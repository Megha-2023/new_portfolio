# Megha Panchal Portfolio

Static professional portfolio website presenting two complementary services:

- Python and backend development
- Computer-science teaching and training

MLOps is presented as complementary technical expertise.

## Run locally

Open `index.html` directly in a browser, or use the **Live Server** extension in VS Code.

## Push to GitHub

Extract these files into your local `new_portfolio` repository, then run:

```bash
git add .
git commit -m "Add professional portfolio website"
git push origin master
```

If your local branch is named `main` instead, replace `master` with `main` in the final command.
